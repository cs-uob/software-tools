# Collaborating using Git

[lecture slides](./slides.md)

Continuing from last week, we will be carrying on our focus on `git`, the version
control system. This week we will be moving away from using Git individually,
and focusing on how to use Git in collaboration with others.

## Pre-reading

This week there are two Git manual pages we want you to read: 
  - `man git merge`
  - `man git rebase` 

You are not expected to learn all of the many options and configuration
variables, but should read the conceptual explanations in all the other
sections.


## Exercises

For this week's lab you are going to practice working with others using
a Git forge.  You will need to work in *at least* pairs for this. Need
someone to work with?  Ask the person you're sitting next to.

- [Collaborating with access](./lab/pushpull.md)
- [Collaborating without access](./lab/pullrequest.md)
- [A puzzle](./lab/puzzle.md)
