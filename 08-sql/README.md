# Relational Databases: Creating Tables in SQL

[lecture slides](./slides.md)

This week and next week we are focusing on _relational databases_ as important
tools for storing and accessing data, and the use of a _structured query
language_ (SQL) for creating, accessing and manipulating data stored in a
relational database. This week in particular we are focused on database design
at the schematic level, including concepts of database organisation and
normalisation, as well as how to realise this in a local SQLite database.


## Pre-reading

The most important thing to understand for this week's lab is how to
conceptually organise relational databases. Please read [this
chapter](https://harpercollege.pressbooks.pub/relationaldatabases/chapter/normalization/)
to learn more about functional dependencies, keys, and the two most important
normal forms.
