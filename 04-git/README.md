# Version control with Git

[lecture slides](./slides.md)

For the next two weeks we are focusing on one specific tool: the version control
system known as `git`. In even moderately complex software projects, tracking
the different versions of a set of files over the course of development becomes
highly complicated. Professional developers -- especially when collaborating --
almost always use a version control system that simplifies these problems. The
most widely-used version control system, by a signifcant margin, is `git`, and
we will be focusing on how you can use `git` to track your own projects and
collaborate with others.

## Pre-reading

For this week, we want you to read the Git tutorial that comes bundled with the
tool before you tackle the lab. On your Debian VM (or any comparable system with
git installed), type `man gittutorial`, then read the tutorial and work through
the instructions.
