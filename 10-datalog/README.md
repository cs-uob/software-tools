# Datalog

[lecture slides](./slides.md)

This week we are continuing our focus on data storage tools, but moving on from
relational databases to slightly more esoteric approaches. Datalog is a
declarative programming language that can be used to create _deductive
databases_ that capture data structures that are difficult to manage in
relational databases.
