# Testing

[lecture slides](./slides.md)

This week is centred on the role of _testing_ in software development. In
particular, we will be tackling the concept of _unit tests_ and how to practice
_test-driven development_. We also cover how to make use of GitHub Actions to
run a test suite every time your repository changes. While we practice all of
this using a particular testing framework for C, testing is something that can
be integrated across your development in any language.
