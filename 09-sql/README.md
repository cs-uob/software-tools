# Relational Databases: Building Queries in SQL

[lecture slides](./slides.md)

This week we are continuing our focus on relational databases. While last week
we focused on database _creation_ and questions of database schema design and
normalisation, this week we are looking more generally at SQL queries, and in
particular how to use SQL queries to extract information from databases. 


## Pre-reading

The crucial reference for this week's lab is the [SQLite syntax guide for SELECT
statements](https://www.sqlite.org/lang_select.html). Most of the lab questions
can be solved with simple SELECTs from appropriately-joined tables.
